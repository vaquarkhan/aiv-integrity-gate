## Generated Markdown

Files under benchmark `results/` directories are generated evidence. They should be regenerated by their owning script rather than manually rewritten for tone. Public product claims must not be inferred from generated fixture summaries without reading the methodology.

## Documentation validation

```bash
python scripts/validate-docs.py
python docs/images/validate_visuals.py
```

The doc validator checks all local Markdown links, all 24 module READMEs, prohibited punctuation, stale image references, and minimum module-guide sections.
