What was executed

This is every prs/*.json file in the stored corpus: the Airflow year folder, the Airflow proof folder, and the other project folders. It is not the 555-case sample and not the 55-case fixture subset. The 15,575-row index has titles, bodies, and line counts only. It has no diff, so AIV cannot score it. A block is a gate finding. It is not a label that the pull request is AI slop. Unscored is not a pass.

Of these files, 1,605 had been scored earlier. Those verdicts are the same, except two Airflow files that were previously unscored because the base file could not be fetched. Those two, pull requests 61939 and 69095, are now blocked for an AI-generated marker. The other 493 files are the Airflow year folder, scored in this run. Eighteen Airflow pull requests are stored in both Airflow folders. Each of those pairs has the same verdict.
