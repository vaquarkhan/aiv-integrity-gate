Read this first

All local rows and stored patches were processed. Only actual AIV executions are performance denominators. The percentage of all real AI slop caught is unknown. AIV does not detect who or what wrote the code. It blocks objective, mechanically verifiable defects such as unresolved merge conflict blocks, unauthorized Git submodule links, edit tool artifacts and placeholder text left on the added lines of a change. Disclosure, merge and closure status are context, not defect truth.
