# Airflow PR pattern labels (stored corpus)

Generated by `benchmarks/airflow/scripts/label-pr-slop-patterns.py` from data already in the benchmark repository. Labels describe the change, not the author. Heuristic labels (tier B) are candidates for review.

- Tier A (index, 15,575 PRs: title, body, size, outcome): 15575 PRs, 14700 decided, baseline merge rate 76.6%; 11988 not bot/backport/release (`human`).
- Tier B (stored patches): 1148 PRs, 1078 decided, baseline merge rate 72.5%; 1030 not bot/backport/release (`human`).
- Tier C (real AIV on checkouts): 627 PRs; all findings: density.entropy 3, invariant.placeholder 2, density.ldr 1.

## What the data cannot show

- `commit-churn` needs per-commit file lists; the corpus stores only the final diff.
- Hallucinated APIs and reuse of existing helpers need the repository at the PR base. Tier C (real AIV on checkouts) covers this for 627 PRs; tier B only sees code duplicated inside the PR.
- Patches are not stored for every PR, and very large PRs are under-represented in tier B.
